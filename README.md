# Schnier Family Tree

Version **1.5.0**. Static site for GitHub Pages.

## Publish

Unzip. Upload every file in this folder to the **root** of a public GitHub repo (`index.html` must sit at the repo root, not inside another folder).

Repo Settings → Pages → Deploy from a branch → `main` / `/ (root)`.

On your iPhone, confirm the header says **v1.6.0**. If it still says 1.3.0 or 1.4.0, Safari has the old files cached: close the tab, then open the Pages URL with `?v=1.6.0` on the end once.

## Use

- Tree runs **top to bottom**: oldest generations above, Morgan, Jacob, and the triplets below.
- Tap a name for a **popup biography**. Close with the **×** or by tapping the dark area.
